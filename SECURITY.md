# Security

Keytune talks to keyboards over USB, and its app macros can press keys, paste text, open files and run shell commands that you define. Please report anything that could let something other than you trigger those actions, or that could damage a keyboard's configuration, privately through [GitHub's security advisories](../../security/advisories/new) rather than in a public issue.

Please don't import macro or profile files from people you don't trust: an app macro can run any shell command.
